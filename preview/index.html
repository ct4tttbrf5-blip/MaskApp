这一版做了什么

原生 SwiftUI四个页面设备连接、护理控制、使用记录、设置与调试日志，全部可交互。
倒计时自动停止到点自动下发停止指令，并把模式、档位、实际时长写入记录。
内置演示模式协议未定时用模拟设备跑通全流程，连接、指令、状态帧走同一套逻辑。
协议集中在一个文件BLEConfig.swift 填好 UUID 与指令字节即可对接真机，其余代码不用改。

怎么玩这份预览

1 · 先连设备在「设备」页点扫描，出现两台模拟设备，点任意一台完成连接。
2 · 开始护理切到「护理」，选模式 / 档位 / 时长，点开始。进度环会走动，到点自动结束。
3 · 看记录结束后「记录」页会多出一条，含模式、档位、实际时长和完成状态。
4 · 看日志「设置」页的调试日志会记录每次下发的十六进制指令，和真机调试时一致。
网页版 ≠ 原生 App本页可用手机 Safari「添加到主屏幕」全屏运行，零数据线、零签名；但 iOS 浏览器不支持蓝牙，无法控制设备。真正控硬件仍需装 SwiftUI 原生 App，见 README 第三节。
