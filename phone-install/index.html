下载 MaskApp-unsigned.ipa
953 KB · com.dnjswork.maskapp · iOS 16.0+

下载后怎么装

  1. Safari 下载完成后，打开「文件」App → 「下载」文件夹，能看到这个 .ipa。
  2. 打开 AltStore，用和电脑 AltServer 相同的 Apple ID 登录。
  3. 底部 My Apps → 左上角 + → 选刚下载的 IPA。
  4. 等待签名完成，桌面出现「电子面膜」图标即可打开。
注意 这个 IPA 是未签名的，直接点击不会有反应，必须经 AltStore 或 AltServer 签名。
免费 Apple ID 签名有效期 7 天；通过 AltStore 装的 App 可以在同 WiFi 下自动续签，用 AltServer「Sideload .ipa」直装的则不会自动续签，到期需在电脑上重装一次。
电脑要开着、本窗口的服务不能关，且手机与电脑在同一 WiFi。
